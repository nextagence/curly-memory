# Окошко — запись для мастеров

PWA без зависимостей: расписание, клиенты, услуги, запись клиентов по ссылке. Выбор гео и валюты.
Работает на iPhone и Android (Safari/Chrome → «На экран Домой»). Нужен только Node 20+.

## Запуск

```bash
node server.js            # http://localhost:3000
node test/smoke.mjs       # проверка API (17 проверок)
node test/reminders.mjs   # напоминания на заглушках Telegram/WhatsApp (11 проверок)
```

Данные: `data/db.json` (создаётся сам). Бэкапьте этот файл.

## Гео и валюты

Включаются переменными окружения. Страна задаёт валюту по умолчанию и часовой пояс. Валюту можно сменить отдельно.

```bash
ENABLE_GEOS=KZ,AE,TR,US,RU   # по умолчанию только KZ
ENABLE_CURRENCIES=EUR        # валюты сверх валют включённых стран
```

Новая страна: одна строка в `config.js` → `GEOS` (название, валюта, часовой пояс, подсказка телефона).
Цены форматируются через `Intl.NumberFormat`: `180 AED`, `12 500 ₸`.

## Напоминания клиентам (за 24 часа и за 2 часа)

Включаются, когда задан хотя бы один канал. Мастер может выключить их в настройках.

**Telegram** (проще, бесплатно)
1. @BotFather → `/newbot` → получите токен и username.
2. `TELEGRAM_BOT_TOKEN=... TELEGRAM_BOT_USERNAME=okoshko_bot node server.js`
3. После записи клиент видит кнопку «Получать напоминания в Telegram», жмёт Start — привязка готова. Для клиента, внесённого вручную, ссылку можно скопировать в карточке клиента. `/stop` в боте отключает напоминания.
4. Бот сам опрашивает Telegram (long polling), публичный адрес и webhook не нужны.

**WhatsApp Cloud API** (работает по номеру телефона, но сложнее)
1. Meta Business → WhatsApp → получите `WHATSAPP_TOKEN` (постоянный токен системного пользователя) и `WHATSAPP_PHONE_ID`.
2. Создайте и согласуйте шаблон категории Utility, язык `ru`:
   `Напоминание о записи: {{2}} у мастера {{1}}, {{3}}. Если планы изменились: {{4}}`
   ({{1}} мастер, {{2}} услуга, {{3}} когда, {{4}} контакт).
3. `WHATSAPP_TEMPLATE=имя_шаблона` (и `WHATSAPP_LANG=ru`, если язык другой).
4. Сообщения уходят только клиентам, поставившим галочку согласия на странице записи (или отмеченным мастером в карточке клиента). Это требование Meta.

Правила отправки:
- Приоритет: Telegram, если клиент подключён, иначе WhatsApp при согласии.
- Если клиент записался позже момента напоминания (например, за 5 часов до визита), 24-часовое не отправляется.
- Просроченные напоминания не шлются: «за 24 ч» не позже чем за 3 часа до визита, «за 2 ч» не позже чем за 30 минут.
- Перенос записи пересчитывает напоминания. Отмена и «Пришёл» их останавливают.
- Сбой отправки повторяется до 3 раз. Статус виден в карточке записи у мастера.

## Деплой на VPS

```bash
PORT=3000 ENABLE_GEOS=KZ,AE TRUST_PROXY=1 node server.js
```

- Нужен HTTPS (иначе PWA не установится). Самый простой путь: Caddy → `reverse_proxy localhost:3000`.
- `TRUST_PROXY=1` — только за прокси: берёт IP клиента из `X-Forwarded-For` для лимитов.
- Держите процесс через systemd или pm2.

## Как работает запись

1. Мастер регистрируется (ссылка-логин, пароль, страна, валюта), добавляет услуги.
2. Ссылка `https://домен/m/ваша-ссылка` — в Instagram/WhatsApp/Telegram.
3. Клиент выбирает услугу, день, свободное время, оставляет имя и телефон.
4. Сервер сам считает свободные слоты (рабочие часы, выходные, длительность услуги) и не даёт занять одно время дважды.
5. Мастер видит запись в расписании, звонит или пишет в WhatsApp, отмечает «Пришёл» / «Отменить», переносит.

## Структура

```
server.js        API + статика (без зависимостей)
reminders.js     напоминания: планировщик, Telegram, WhatsApp
config.js        гео, валюты
public/          PWA: index.html, app.js, styles.css, sw.js, manifest
test/smoke.mjs   сценарий API
tools/make-icons.py  генератор иконок (Pillow)
```

## Ограничения первой версии

- Хранилище — JSON-файл. До сотен мастеров нормально; дальше переходите на SQLite/Postgres (слой данных — один блок в `server.js`).
- Напоминания проверены только на локальных заглушках API. Перед запуском отправьте тестовое сообщение через реальный бот и WhatsApp-номер.
- Нет платежей.
- Интерфейс только на русском.
- Время хранится «настенное», в поясе мастера; у стран с несколькими поясами (США) используется один.
- Восстановления пароля нет: сброс вручную в `db.json`.
